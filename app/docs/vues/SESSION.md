# Vue — Session d’apprentissage

## Objectif

Relier plusieurs activités dans une expérience continue. La session orchestre la
réactivation, la découverte, la compréhension et le transfert sans donner
l’impression d’ouvrir plusieurs outils indépendants.

Le détail des micro-écrans et de leurs enchaînements est disponible dans
[`session/README.md`](session/README.md).

## Avant de commencer

- thème et objectif communicatif ;
- durée estimée ;
- aperçu des modalités ;
- contenus à télécharger ;
- réglage rapide du son ;
- option de session courte.

Finn peut expliquer brièvement pourquoi la session est proposée : unités dues,
prochaine étape du parcours ou compétence à renforcer.

## Pendant la session

L’en-tête affiche uniquement :

- progression dans la session ;
- titre de l’étape ;
- pause et sortie ;
- accès aux paramètres d’aide.

Chaque activité conserve son lecteur spécialisé. Les transitions expliquent le lien
avec l’étape précédente : « Vous venez d’entendre cette demande ; retrouvez-la dans
un message différent. »

## Séquence typique

1. rappel court d’une unité déjà rencontrée ;
2. dialogue audio compréhensible ;
3. question sur la situation ;
4. lecture dans un nouveau contexte ;
5. seconde vérification de compréhension ;
6. rappel productif ou flashcard si pertinent ;
7. synthèse.

La session peut omettre une étape si elle n’apporte pas de preuve nouvelle.

## Sortie et reprise

L’utilisateur peut quitter entre deux activités ou pendant un lecteur. Finn
enregistre :

- la dernière étape terminée ;
- la position audio ou textuelle ;
- les réponses déjà données ;
- les aides utilisées ;
- les rencontres déjà comptabilisées.

Une activité abandonnée très tôt ne doit pas être comptée comme une rencontre
d’apprentissage complète.

## Fin de session

- objectif travaillé ;
- unités découvertes et renforcées ;
- exemples de réussite dans un nouveau contexte ;
- éléments encore fragiles ;
- prochaines rencontres prévues ;
- action facultative pour continuer librement.

Le bilan évite les récompenses trompeuses fondées uniquement sur le nombre de clics.

## États

- contenu manquant ;
- interruption système ;
- session partiellement disponible hors ligne ;
- aucune activité de variante disponible ;
- charge réduite en cours de session ;
- activité ignorée volontairement.

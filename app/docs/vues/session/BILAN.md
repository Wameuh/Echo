# Session — bilan

## Objectif

Terminer la session avec une synthèse utile : ce qui a été compris, ce qui reste
fragile et comment Finn organisera la suite.

## Résumé principal

- objectif communicatif travaillé ;
- activités terminées ;
- unités découvertes ;
- unités réactivées dans un nouveau contexte ;
- durée réelle ;
- prochaine activité recommandée.

Le bilan privilégie une formulation concrète : « Vous avez reconnu `Haluaisin…`
dans un dialogue et un message » plutôt qu’un score abstrait.

## Acquis observés

Pour chaque unité importante :

- contexte de découverte ;
- modalités rencontrées ;
- réussite autonome ou aidée ;
- compétence encore faible ;
- prochaine rencontre estimée.

Toucher une unité ouvre sa fiche complète. Les exemples y utilisent le texte
interactif avec traduction du mot et de la phrase.

## Éléments à revoir

Finn indique pourquoi une unité reviendra bientôt :

- sens non compris ;
- transcription nécessaire ;
- rappel oral difficile ;
- forme confondue ;
- réussite limitée à un seul contexte.

Une flashcard peut être proposée lorsque les critères de sélection sont remplis.
Elle n’est jamais créée automatiquement pour tous les mots consultés.

## Planification

Le bilan peut annoncer :

- « demain : courte réactivation à l’écoute » ;
- « dans trois jours : nouvelle lecture avec cette construction » ;
- « plus tard : utilisation dans une autre situation ».

Ces indications restent approximatives car la prochaine session peut regrouper
plusieurs unités dues.

## Actions

- terminer ;
- continuer avec une activité libre ;
- revoir une phrase difficile ;
- ouvrir les acquis ;
- signaler une erreur dans le contenu.

## États

- session complète ;
- session courte ;
- activité ignorée ;
- données insuffisantes pour conclure ;
- progression enregistrée localement ;
- contenu suivant indisponible hors ligne.

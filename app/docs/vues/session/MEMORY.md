# Session — Memory de phrases

## Objectif

Faire reconnaître visuellement quelques mots concrets déjà rencontrés.

## Placement

Le Memory vient après la compréhension du texte et avant les mini-jeux. Il ne
révèle donc aucune réponse avant le rappel oral ou les questions de lecture.

## Interaction

- douze cartes retournées forment six paires ;
- une paire réunit un mot finnois et un dessin ;
- les cartes n’affichent ni traduction ni phrase d’exemple ;
- deux cartes différentes se retournent après un court délai ;
- une paire correcte reste visible ;
- aucune limite de temps ni score compétitif n’est utilisé ;
- les animations disparaissent lorsque la réduction du mouvement est activée.

Les mots ont déjà été contextualisés et partagent les mêmes identifiants d’unités
que l’audio, la lecture, les mini-jeux et les flashcards. Une tentative alimente
les acquis temporaires de la session.

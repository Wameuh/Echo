# Session — écoute globale

## Objectif

Comprendre la situation et l’intention générale avant de travailler les phrases en
détail.

## Premier passage

L’écran affiche :

- les personnages ;
- une animation discrète indiquant qui parle ;
- lecture, pause et reprise ;
- progression dans le passage ;
- action « Réécouter » après la fin.

La transcription et la traduction restent cachées au premier passage lorsqu’il
s’agit d’une activité de compréhension.

## Vérification rapide

Après l’écoute, une question très courte demande par exemple :

- où se déroule la scène ;
- ce que souhaite un personnage ;
- si les personnes se connaissent ;
- quelle émotion ou intention générale est exprimée.

Cette vérification ne porte pas encore sur chaque mot.

## Second passage

Selon le résultat, Finn propose :

- réécoute sans aide ;
- réécoute avec illustration renforcée ;
- transcription synchronisée ;
- découpage par réplique ;
- passage direct à la répétition si le sens global est compris.

Lorsque la transcription est ouverte, chaque mot utilise le
[`texte interactif`](../TEXTE_INTERACTIF.md) : traduction contextuelle du mot et
traduction de la phrase entière.

## Données observées

- nombre d’écoutes ;
- réponse de compréhension ;
- transcription ouverte ou non ;
- mots consultés ;
- vitesse utilisée ;
- interruptions importantes.

Une première écoute difficile ne constitue pas un échec définitif. Elle guide le
niveau d’assistance de la suite.

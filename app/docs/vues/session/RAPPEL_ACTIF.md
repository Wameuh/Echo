# Session — rappel actif

## Objectif

Faire produire une expression avant de jouer la réponse modèle. Cette vue constitue
le cœur des séquences audio inspirées de Pimsleur.

## Consigne

La consigne décrit une intention, par exemple :

> Dites en finnois : « Je voudrais du café. »

Elle peut aussi prolonger un dialogue :

> Mikko vous demande ce que vous souhaitez. Répondez que vous voudriez du café.

La seconde forme est préférable lorsqu’un contexte est disponible.

## Écran de réponse

- consigne ;
- personnage qui attend la réponse ;
- pause suffisamment longue ;
- indicateur discret du temps restant ;
- action « Entendre la réponse » ;
- aide graduelle facultative.

La V1 n’enregistre pas la voix par défaut. L’utilisateur répond à voix haute puis
compare avec le modèle.

## Aides

1. indice sur l’intention ou le premier élément ;
2. mot clé écrit ;
3. traduction ou structure partielle ;
4. réponse modèle complète.

Lorsque du texte cible est affiché après la tentative, il utilise le
[`texte interactif`](../TEXTE_INTERACTIF.md).

## Comparaison

Après la réponse modèle :

- réécouter ;
- répéter une nouvelle fois ;
- afficher la phrase et sa traduction ;
- s’autoévaluer : oublié, difficile, correct ou facile.

Finn ne prétend pas que l’autoévaluation mesure précisément la prononciation. Une
future analyse vocale devra distinguer contenu reconnu, fluidité et sons produits.

## Variation espacée

Lors d’une rencontre ultérieure, l’intention reste la même mais le contexte change :

- café : demander du café ;
- office du tourisme : demander une carte ;
- hôtel : demander une chambre.

Une réussite dans le nouveau contexte fournit une preuve plus forte qu’une seconde
réponse au même dialogue.

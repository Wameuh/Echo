# Vue — unité linguistique

## Objectif

Regrouper tout ce que Finn sait sur un mot, une expression ou une construction,
ainsi que les preuves de maîtrise et les activités où l’unité apparaît.

## En-tête

- forme canonique ;
- type : mot, expression, construction ou point grammatical ;
- traduction principale ;
- langue, niveau et registre ;
- bouton d’écoute ;
- état global : découverte, consolidation ou robuste.

## Sens et usages

- sens principaux ;
- sens contextuels déjà rencontrés ;
- catégorie grammaticale ;
- formes importantes ;
- constructions associées ;
- notes de registre ;
- erreurs ou confusions fréquentes.

Les explications sont adaptées au niveau actuel. Les détails plus avancés restent
repliés.

## Exemples

Les exemples proviennent de plusieurs contextes :

- dialogue déjà écouté ;
- lecture déjà parcourue ;
- exemple supplémentaire validé ;
- prochaine utilisation prévue.

Chaque exemple utilise le [`texte interactif`](TEXTE_INTERACTIF.md). Toucher un mot
affiche sa traduction et celle de la phrase entière. L’expression actuellement
consultée reste visuellement mise en évidence.

## Maîtrise par compétence

- compréhension orale ;
- compréhension écrite ;
- rappel du sens ;
- production orale ;
- production écrite.

Pour chaque compétence, Finn indique la dernière preuve, les aides utilisées et la
prochaine rencontre planifiée. Il évite une précision numérique trompeuse lorsque
l’historique est insuffisant.

## Activités liées

- activités déjà effectuées ;
- nouveaux contextes disponibles ;
- activité recommandée ;
- lectures ou audios où l’unité est seulement présente ;
- famille communicative associée.

Le système privilégie une activité différente des dernières rencontres.

## Flashcard

La vue précise si une carte existe et pourquoi : objectif central, difficulté,
besoin productif ou ajout manuel. L’utilisateur peut :

- créer une carte ;
- changer son type ;
- la suspendre ;
- conserver uniquement les rencontres contextuelles.

## Historique

- date et modalité des rencontres ;
- contextes distincts ;
- réussites autonomes ;
- aides consultées ;
- erreurs significatives.

Les répétitions identiques dans une même activité sont regroupées pour ne pas
donner une impression artificielle de maîtrise.

## États

- unité jamais étudiée ;
- unité rencontrée mais non ciblée ;
- donnée grammaticale partielle ;
- audio non disponible ;
- traduction en cours de correction ;
- unité fusionnée avec une autre version du contenu.

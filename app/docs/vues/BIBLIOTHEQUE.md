# Vue — Bibliothèque

## Objectif

Permettre l’exploration libre des leçons, textes, histoires et contenus audio sans
remplacer la session recommandée.

## Contenu

La bibliothèque propose des catégories simples :

- lectures courtes ;
- histoires suivies ;
- dialogues audio ;
- contenus déjà commencés ;
- téléchargements ;
- favoris.

Les flashcards ne sont pas présentées comme une bibliothèque de contenus principale.
Elles sont accessibles depuis les acquis et les unités linguistiques.

## Recherche et filtres

- langue ;
- niveau CECR ;
- thème ;
- durée ;
- modalité ;
- proportion estimée de vocabulaire connu ;
- téléchargé ou disponible en ligne ;
- nouveau, commencé ou terminé.

La recherche peut porter sur un titre, un thème ou une unité linguistique. Chercher
`kahvi` peut ainsi retrouver des textes et dialogues où cette unité apparaît.

## Carte de contenu

- titre et illustration éventuelle ;
- type de contenu ;
- niveau ;
- durée ou longueur ;
- pourcentage estimé de contenu compréhensible ;
- nouvelles unités prévues ;
- progression ;
- disponibilité hors ligne.

Le pourcentage est une estimation, pas une note de valeur. L’utilisateur peut ouvrir
un contenu plus difficile en connaissance de cause.

## Détail du contenu

- résumé sans révéler les réponses ;
- objectifs ou thèmes ;
- difficulté personnalisée ;
- aides disponibles ;
- activités liées ;
- provenance et licence ;
- bouton « Lire », « Écouter » ou « Reprendre » ;
- action de téléchargement.

## Imports futurs

Une future section « Mes documents » pourra accueillir EPUB, PDF ou pages Web. Elle
devra afficher l’état de l’analyse, la langue détectée, la difficulté estimée et les
limites éventuelles de traduction ou d’utilisation hors ligne.

## États

- bibliothèque vide pour une langue ;
- aucun résultat de recherche ;
- contenu non compatible avec le niveau ;
- téléchargement en attente ou interrompu ;
- contenu retiré ou licence expirée ;
- mode hors ligne.

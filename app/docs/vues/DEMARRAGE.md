# Vue — démarrage et configuration initiale

## Objectif

Configurer un premier parcours suffisamment personnalisé sans imposer un long
questionnaire avant la première activité.

## Étapes

### Langue étudiée

- choix de la langue cible ;
- nom natif et nom dans la langue de l’interface ;
- registre initial lorsqu’il est pertinent ;
- disponibilité du contenu hors ligne.

Pour le finnois initial, l’interface explique brièvement que le parcours enseigne le
`kirjakieli`.

### Langue des consignes

- langue de l’interface ;
- langue des traductions et explications ;
- exemple de phrase et traduction pour vérifier le choix.

### Expérience actuelle

Choix simples :

- je commence ;
- je connais quelques bases ;
- j’ai déjà étudié cette langue.

Un test de placement reste facultatif. L’utilisateur peut commencer immédiatement
et laisser Finn ajuster les recommandations grâce aux premières activités.

### Objectif

- conversation quotidienne ;
- compréhension de textes ;
- voyage ;
- intérêt personnel ;
- objectif libre.

L’objectif influence les thèmes proposés, pas la structure fondamentale de la
langue.

### Rythme

- durée quotidienne souhaitée ;
- préférence initiale audio ou lecture ;
- téléchargement Wi-Fi uniquement ;
- rappels facultatifs.

Finn précise que toutes les modalités seront utilisées progressivement afin de
construire une compréhension équilibrée.

## Première activité

Le démarrage se termine par une activité très courte donnant immédiatement :

- un contexte compréhensible ;
- une première interaction audio ou textuelle ;
- une démonstration du clic sur un mot ;
- la traduction du mot et de la phrase ;
- une première recommandation expliquée.

## États

- aucune langue disponible hors ligne ;
- reprise d’une configuration interrompue ;
- utilisateur revenant avec des données locales ;
- changement ultérieur de langue de traduction ;
- refus des notifications ;
- test de placement ignoré.

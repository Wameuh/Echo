# Vue — Parcours

## Objectif

Présenter la progression structurée d’une langue : niveaux, unités thématiques,
objectifs et prérequis. Cette vue répond à « où suis-je ? » et « qu’est-ce que
j’apprendrai ensuite ? ».

## Sélecteur de langue et niveau

- langue active ;
- registre lorsque la langue en distingue plusieurs ;
- niveau CECR courant ;
- accès aux autres niveaux ;
- indication des niveaux explorés mais non validés.

Pour le finnois, le parcours initial indique explicitement `kirjakieli`.

## Carte d’une unité de parcours

Chaque carte affiche :

- titre et situation communicative ;
- objectifs linguistiques ;
- modalités disponibles ;
- durée estimée ;
- progression globale ;
- unités essentielles maîtrisées ou à renforcer ;
- téléchargement hors ligne ;
- état : à découvrir, en cours, consolidation ou acquis.

L’état « acquis » demande des preuves dans plusieurs contextes. Terminer une leçon
audio ne suffit pas à lui seul.

## Détail d’une unité de parcours

- description de la situation ;
- objectifs et prérequis ;
- expressions centrales ;
- activités principales : audio, lecture et compréhension ;
- activités de consolidation ;
- difficulté estimée pour l’utilisateur ;
- raison des éventuelles recommandations ;
- bouton pour commencer ou reprendre.

Les expressions centrales ouvrent la
[`vue d’unité linguistique`](UNITE_LINGUISTIQUE.md). Les exemples textuels utilisent
le [`texte interactif`](TEXTE_INTERACTIF.md).

## Liberté et prérequis

Finn recommande un ordre sans verrouiller artificiellement tout le contenu.
L’utilisateur peut explorer une unité avancée ; l’interface distingue alors
« explorée » de « maîtrisée » et signale les prérequis susceptibles de manquer.

## États

- parcours non commencé ;
- unité recommandée ;
- activité en cours ;
- prérequis incomplets ;
- contenu téléchargé ou distant ;
- nouvelle version du contenu disponible ;
- niveau terminé mais consolidation restante.

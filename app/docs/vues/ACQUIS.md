# Vue — Acquis

## Objectif

Rendre la progression compréhensible sans la réduire à un score unique. La vue
montre ce que l’apprenant comprend, ce qu’il peut produire et ce qui doit revenir
prochainement.

## Résumé

- unités découvertes ;
- unités en consolidation ;
- unités robustes dans plusieurs contextes ;
- temps passé récemment ;
- révisions prévues ;
- répartition par compréhension orale, lecture et production.

Les statistiques privilégient les tendances plutôt que la comparaison sociale.

## Compétences

Une visualisation simple distingue :

- compréhension orale ;
- compréhension écrite ;
- rappel du sens ;
- production orale ;
- production écrite.

La maîtrise peut être différente selon la compétence. Une expression reconnue à
l’écrit peut rester à renforcer à l’écoute.

## Liste des unités

Filtres disponibles :

- thème ;
- niveau ;
- type : mot, expression ou construction ;
- état de maîtrise ;
- prochaine échéance ;
- difficulté ;
- présence ou absence de flashcard.

Chaque ligne contient la forme principale, le sens, l’état, les compétences fortes
ou faibles et la prochaine rencontre prévue. Un toucher ouvre la
[`vue d’unité linguistique`](UNITE_LINGUISTIQUE.md).

## Calendrier de réactivation

Le calendrier présente une charge estimée en minutes. Il inclut toutes les
modalités planifiées, pas seulement les cartes.

L’utilisateur peut réduire temporairement sa charge. Finn reporte alors les
éléments secondaires et conserve en priorité les unités essentielles ou fragiles.

## Historique

- activités récentes ;
- réussites autonomes ;
- aides fréquemment utilisées ;
- transferts réussis dans un nouveau contexte ;
- erreurs récurrentes.

L’historique détaillé reste secondaire. L’écran principal formule des observations
actionnables, par exemple « compris à l’écrit, à revoir à l’écoute ».

## États

- historique insuffisant ;
- aucune unité due ;
- nombreuses unités fragiles ;
- données locales seulement ;
- synchronisation future en attente ;
- recalcul de maîtrise après changement d’algorithme.
